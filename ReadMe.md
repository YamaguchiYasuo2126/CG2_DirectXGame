# 実装方法について

### 三角形を動かす
ImGui::DragFloat3を用いて三角形のtransform変数のScale,Rotate,Translateを変更できるようにしました。

なお、DepthBufferの利用の加点要素に取り組む際に三角形を2つに増やしたため、三角形のtransform変数と、WVPリソースを2つのオブジェクト用に2つ作成しました。

また、WVP行列をそれぞれのバッファに書き込み、描画コマンドを2回に分けるといった手順を踏んで、ImGuiを利用して個別にSRTを操作できるようにしました。
<br>

### Textureを貼る
CG2_03_00の資料の手順を踏んで実装しました。
<br>

### DepthBufferの利用
CG2_03_01の資料の手順を踏んで実装しました。
<br>

### Textureの動的切り替え
まず、Textureを配列を使って複数枚読み込めるようにしました。

そして、ImGui::Comboを利用して読み込んだ複数のTextureを切り替えられるようにしました。

その次に、ImGuiで選択された、現在選択されているテクスチャのインデックスを保持する変数に、対応するGPUハンドルを渡すようにしました。

なお、DepthBufferの利用の加点要素に取り組む際に三角形を2つに増やしたため、オブジェクトごとに別々のインデックス変数を保持するようにしました。

それぞれのオブジェクトを描画する直前に、対応するテクスチャのGPUハンドルをセットするようにしたことでImGuiを利用して個別にTextureを切り替えられるようにしました。
<br>

### 三角形を利用した映像演出
ImGui::Buttonを利用して、シーン切り替え時などに使えそうな画面切り替え演出のようなものを作りました。(ScreenTransitionという名前のボタンを押すと演出が始まります)

画面全体を埋め尽くす格子状の三角形を扱うための演出専用の頂点バッファとWVP用リソースを作りました。

演出タイマーを用意して、タイマーと格子の列に応じた時間差を使って各三角形をその場で回転させました。

既存の2つの三角形の上から演出が表示されるようにしました。

演出用の三角形にはテクスチャを適用せずにマテリアルの色のみで描画されるようにしました。

グラデーションとサイン波による色変化をしながら格子状の三角形が回転して裏返っていくようにしました。

カメラを適用して、回転する瞬間にカメラに向かって巨大化しながら飛び出してくるようにしました。
